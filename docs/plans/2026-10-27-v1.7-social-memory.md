# V1.7：社交适配、双语回复和对象记忆

在 V1.6 最新实现上修改，保留去 AI 味独立开关与真人感优先级。原始上游知识和许可保留，新增整合资料并扩大有预算的场景检索。

验收范围：
- 六条候选兼顾承接、欣赏、幽默、互惠与边界；不强制暧昧、不机械讨好。
- 外语正文、中文释义分字段保存；复制/填入只有正文，建议中文，一轮生成双语。
- 多社交平台走通注册、窗口识别、视觉读取、会话校验和填入；未知布局不能猜坐标或跳过聊天身份检查。没有真机的平台标注待验证。
- 选句页面改名、移除自动接话入口；删除主页完整咨询入口；三处胶囊大小控件每次 ±1%；开关提示同行小字。
- 面板菜单提供复制单句分析，不截图，不写成真实聊天记忆；旧会话候选不可跨聊天填入。
- 对象页显示双方原话，按上一层返回；自动提取有原文依据的资料和关系观察，用户确认优先。每对象独立加密保存，迁移不能丢失撤销、删除和锁定数据。
- 日志保留阶段与数量等脱敏信息，不保存剪贴板或聊天正文。

验证：先增加核心失败回归；完整核心测试、Android 编译、设置测试、知识包/来源/存储策略检查、签名和 APK 内容核查。手机未连接，系统、社交软件真机操作列为待验证，不宣称已全部实测。
