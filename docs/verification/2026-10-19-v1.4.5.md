# V1.4.5 — 同页选句判断、紧凑建议与启动恢复

日期：2026-10-19。分支：codex/v1.4.5-inline-judgment。基线：0d59b8b。初始实现：5701382，最终实现：4721017。

## 需求与实现

- 单聊和群聊的判断分析在同页显示每句对方原话与判断，原话无输入框边框；右侧短按钮「指定回复」携带原始消息 ID 生成六条，恢复自动接话仍可用。
- 判断输入包含全部已读消息，保持原顺序，包括目标之后已读到的内容；目标独立标明。Jev 与自定义判断两种协议均保留该目标，解码按目标 ID 关联结果，拒绝缺失、自发及重复目标 ID。
- 页面不展示「参考原文」。可见卡片按需串行判断，沿用会话/模型版本缓存；离开前台不排队分析其他行，已发出的判断可完成，返回保留滚动位置。关闭页面取消未完成请求。
- 「详情」改为「建议」。面板内显示怎么接、注意和一个后续分支；积极/含糊/拒绝本地切换，重开使用当前卡片已获取结果，每次只展开一条。建议展开高度不参与外层面板增高，候选区可滚动。
- 启动已发现的风险：MainActivity.render 在首次绘制时同步调用 AppSettings.load，可能触发加密存储和 AndroidKeyStore；无障碍服务初始化同样依赖该设置。两者改用共享后台单次初始化，8 秒后显示慢加载状态，失败可重试，销毁的订阅者不接收迟到结果。未删除配置或更改权限。
- 无障碍「已开启但尚未连接」与「未开启」分开显示。组件名、应用 ID、加密密钥别名保持原值，覆盖更新签名不变。

## 限制与待验收

- 用户报告的覆盖安装后「正在更新」文案不在已检查源码中。已确认应用存在同步首读设置的风险并作处理，但缺少故障现场日志，不能认定它就是原症状根因，不能宣称覆盖安装已在真机修复。
- OPPO/iQOO 的系统截图限制按用户要求继续搁置；本次未改截图接口，也未操作第三方应用设置。
- 未连接手机；没有真实判断/回复模型调用，不能声称昵称识别率、语义正确率或帧率已实测提升。
- Android 官方建议减少启动时阻塞操作：https://developer.android.com/topic/performance/anrs/keep-your-app-responsive 。这支持后台初始化处理，不是本次用户故障的现场根因证据。
- 同一位独立审查者复查了初始实现和后续修正，无剩余 Critical/Important/Minor，允许进入设备验收。初审发现判断缓存 50 条不足以覆盖 200 条群聊；新回归在旧容量上观察到 RED，容量扩为 200 后全量测试通过。新增可见性检查和首屏布局后滚动处理，后台返回仍保留位置。
