# 对话军师 V1.3.10

主页新增清缓存按钮，并改进现有 Android 11+、ARM64 设备上的屏幕、字体与权限入口兼容处理。

## 本次更新

- **清除缓存**：主页显示临时缓存大小，点击后在后台清理，结束时显示释放及剩余大小；无法清理的文件会明确提示。保留 API 密钥、模型配置、回复风格、关系资料、记忆、聊天历史及系统编译缓存。
- **屏幕避让**：页面和候选面板考虑横屏侧边挖孔、刘海与系统导航区域，继续为键盘上方聊天输入栏留出空间。胶囊避开挖孔，并修正避让后拖动、保存位置可能跳回的问题。
- **大字体与窄屏**：操作按钮按可用宽度分配，菜单宽度和文字高度自适应；面板底部整条30dp收起区域固定在底部，短视口也可触达。
- **权限入口**：直接权限页面不可用或被系统拒绝时，尝试标准Android备用设置页面，并保留手动操作提示。
- **保留现有行为**：继续使用 V1.2.13 识别流程、最后一句由我说出时六条候选接着我说的规则，以及不支持毛玻璃时的清晰面板降级。

## 安装与附件

支持 Android 11 及以上、ARM64。安装包与旧版使用同一签名，可直接覆盖安装并保留资料。

- `duihua-junshi-V1.3.10.apk`：安装包。
- `duihua-junshi-V1.3.10-source.zip`：对应版本源码。
- `SHA256SUMS.txt`：安装包、源码包及提交记录的校验值。
- `SOURCE-COMMIT.txt`：对应源码提交。
