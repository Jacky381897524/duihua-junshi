# V1.6 真人感与持久记忆

基于最新 V1.5.3（6df7fcd）开发。版本名 V1.6，versionCode 46。未改动本地模型部署环境，旧版去AI味策略正文与旧安装包保留。

## 已实现

- 首次升级初始化真人感开启、去AI味关闭；随后保留用户选择。设置页与面板菜单共享保存状态，同时开启时真人感优先。关闭真人感后暂停自动学习和使用真人感资料；两者均关闭恢复原生成规则。开关不会触发截图或自动生成。
- 新增加密持久文档 `files/private-data/personal-memory-v1.enc`，使用已有 Android Keystore AES-GCM 与原子替换机制，独立24MiB上限。清除缓存不涉及此目录；卸载/清除应用数据会删除。达到上限时停止新增保存并记录故障，继续生成已有候选，不自动删用户资料。
- 手动读取时按平台/昵称、群/成员归属增量保存真实原话和可见时间。来源ID不依赖窗口、临时消息ID或本次读取时间；重读、重叠读取、刷新不重复记忆/累计互动。无昵称的群成员不合并成一个“对方”。手动绑定误识别别名可撤销。
- 本人资料与对方资料分开：喜好、厌恶、习惯、边界、性格观察、关系依据、事件与事实陈述。自动整理只保留来源原话；模型不能凭空写入概括性事实或指定归属。性格和关系观察暂定，用户修正和确认优先。
- 新主页入口“真人感与记忆”支持原话/来源/日期检查、手动新增/编辑、关系确认、别名关联、实际候选修改反馈、暂停/撤销/删除，以及UTF-8文本粘贴或文件导入。群聊导入要求具体成员昵称。完整咨询的示例、草稿和模拟不自动学习。
- 口吻依据包括同对象的近期本人原话、确认的修改、历史表达长度/标点/结尾统计；旧内容贡献语言习惯，不复制成当前话题。每次检索相关对象资料，最多14项并缩减至4200字符；当前聊天仍是独立权威输入。
- 生成仍为六条候选加一次Jev排序，默认Jev问题数13；不逐条调用去AI味模型。真人感与生成模式/本次资料保存在候选批次，最终显示和旧候选“建议”不被后来的开关切换改写。
- 候选后才调度一批最多24条新原话的辅助分类，输出最多8条分类；本地规则和口吻统计先处理全部新材料。分类使用已配置的回复服务、最多1400输出tokens、有25秒总时限。前台读取、生成、建议和判断可抢占；不持有前台优先级锁进行加密磁盘I/O。取消后原文保留，下次新材料或用户明确重试再处理，刷新不重新触发分类。尚未分类的原文可在管理页查看/继续处理。
- 好感度是互动趋势估计：明确感谢、亲近表达与拒绝等才作为依据；无可靠日期/过期导入不计入当天，同条来源不重复，同类互动递减，正向每日最多3分，越高越慢。不靠分数自动认定真人的恋爱关系。可查看来源、忽略误判并撤销。
- 保留V1.5.3的原生/OCR/视觉时间读取与24小时话题窗口。补上旧版手工记忆、历史的时间字段及过期筛选，避免从背景重新引入旧话题；长期喜好保留日期。未知发送时间不伪造。已读旧消息仍可明确指定回复。
- 新增 MEMORY_READ/LEARN/SAVE/RETRIEVE/EDIT/DELETE 诊断阶段与模式编号（2真人感、1去AI味、0原版），不将记忆、昵称或聊天正文写入诊断日志。
