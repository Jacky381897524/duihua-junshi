# V1.5.3 聊天时间与顶部胶囊

日期：2026-10-23。基于当前 V1.5.2（6f80e8b）及其后审查记录开发，未修改历史安装包、已收录知识或本地模型环境。

## 原因与处理

原视觉提示要求忽略时间，ChatMessage 也没有时间字段。原生解析只把部分时间当作界面元素删除，生成、评分和刷新没有当前话题的时间范围，因此两天前的内容仍可被当成当前发言。

原生、OCR与视觉读取现在保留可见的聊天时间标记，本地按读取时的设备日期解析；相对日期不会随重开或刷新重新解释。只见时钟而没有日期时不猜今天；日期只有天时用该日结束作为保守上界。状态栏、文件名、背景、引用栏和截图内嵌聊天不作为当前消息时间。

自动接话和指定新消息的判断默认排除已能确定超过24小时的内容。首次观察时间只证明消息至少有多旧，不是发送时间；缓存满24小时后也不会继续冒充当前消息。未保存时间的旧版本数据保持未知，升级后需要手动读取一次。

已读原文仍保留。旧消息可手动判断或指定回复，历史目标与当前时间会传入生成及评分。若整段都过期，先反馈并保留上一批结果，不自动重读、截图或调用模型。时间范围变化后清理对应的共同分析、候选去重与判断缓存键，不清除聊天。

消息列表中的旧内容保留但不自动逐条判断，可见时间注明「读取时」。诊断使用 TIME_CONTEXT、EXPIRED_MESSAGE_COUNT 和 TOPIC_EXPIRED，记录数量及过期原因，不记录聊天、昵称或原始时间标记。界面和文档统一使用「顶部胶囊」。
