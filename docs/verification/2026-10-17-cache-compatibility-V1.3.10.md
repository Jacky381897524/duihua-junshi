# V1.3.10：清除缓存与安卓兼容增强

2026-10-17，用户确认按 Android 11+、ARM64 范围增加清缓存与主流安卓兼容处理。

## 行为与边界

- 主页新增缓存按钮，后台统计内部与外部 cache 目录，点击后显示释放和剩余大小。只向清理器传递系统 cacheDir / externalCacheDirs，不传 filesDir、Keystore 或 codeCacheDir。清理保留根目录，不跟随文件或目录链接，记录无法读取/删除的项，支持取消。0字节是合法结果。
- 保留所有密钥、模型配置、全对象和专属风格、资料、记忆、历史以及编译缓存。未加入清除数据、重置配置或清理其他软件的功能。
- Activity 的边距合并系统栏、键盘及 DisplayCutout；悬浮面板使用系统栏与挖孔各边最大安全距离，保留原有72dp输入栏预留。胶囊位置仍以用户左上角选项为准，但避开左角及横屏挖孔。
- 候选按钮按可用宽度分配，菜单宽度受面板约束，菜单文字允许自然增高；较大字体时调整标题、读取及刷新控件高度。底部收起栏仍为30dp，固定在根布局底部，内容和菜单预留对应空间，避免短视口时被挤出。
- 权限设置页依次尝试标准Android入口，没有对应页面或被拒绝时尝试更通用页面；没有可用页面时显示手动操作说明。没有调用未经公开的厂商私有设置接口。
- 继续使用既有 API31+ 毛玻璃能力与省电/不支持时的普通面板降级，没有增加背景采样或常驻识别。
