# 对话军师 V1.4.5（测试版）

本次将 V1.3.10 之后的改动一起同步到 GitHub，保留旧 Release、标签和下载文件。Android 11+、ARM64，应用 ID 和签名沿用旧版。此包与此前邮件交付的 V1.4.5 相同，不含新的截图接口改动。

## 主要变化

- 微信、QQ、抖音支持单聊与群聊按需读取；群聊区分成员、话题、媒体与前文引用，不自动@、原生引用或发送。
- 判断分析直接在每句原话下展示，右侧「指定回复」围绕该句生成六条。判断参考全部已读消息，目标不会被后续最后一句替换；不展示参考原文。
- 可见句子依次判断，同一已读会话／模型复用最多200条结果；后台保留在途判断与滚动位置，不在后台排队判断其他行。
- 「详情」改为紧凑「建议」，展示怎么接、注意和一个后续分支；积极／含糊／拒绝本地切换，每次只展开一条，面板保持原高度。
- 专属风格、全对象风格、模型和悬浮窗设置均可在面板中保存。特殊文字与组合表情昵称保留原文，可校正关联；单聊与群聊风格分开，不读取头像或账号。
- 后台返回保留本次运行中的已读内容与未保存面板草稿；刷新沿用手动读取的上下文和所选目标，填入继续核对当前应用、聊天标题和输入框。
- 主页和辅助服务共用后台首次设置加载，慢加载有状态、失败可重试；区分无障碍已开启但尚未连接与未开启，保留原配置和授权。

## 验证和待确认问题

346项核心测试、16项配置测试通过，应用及Android测试组件编译、Lint、签名、45份知识及许可、ARM64原生库16KB兼容性检查通过，独立代码审查通过。Android界面测试仅编译，未在设备执行；未调用真实模型验证语义、延迟或帧率。

**部分OPPO／iQOO设备点击读取后微信无法手动截图的问题尚未解决。** 已有受保护窗口错误的证据，触发原因仍待诊断，本版未修改截图接口。

**覆盖安装后首次打开卡在「正在更新」的根因尚未确认。** 本版处理了首次设置同步读取的风险，增加后台加载和失败恢复，仍需实际覆盖安装验收，不将原故障标记为已修复。
