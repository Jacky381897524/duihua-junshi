# 对话军师 V1.3.10 使用说明

Android 11+、ARM64 测试版。与原 Jev App 可以共存；使用本项目开发签名。安装新 APK 可覆盖本项目旧版并保留设置。

覆盖安装后将「对话军师」无障碍服务关闭再开启，以重新加载本版输入连接权限，然后进入微信。无需卸载或清除数据；本项目旧版设置会保留。

## 当前版本：清除缓存与兼容增强

首页「连接诊断」下方新增「清除缓存 · 大小」按钮，点击后在后台清理本应用的内部及外部临时缓存，结束时显示已释放和剩余大小。统计和清理不会读取缓存文件正文；目录链接不会被跟随。部分文件不可访问时会提示未完整清理，不会把失败显示成全部成功。

密钥、模型配置、回复风格、关系资料、记忆和聊天历史不属于此次清理范围，均保留；系统编译缓存也保留，避免重新编译造成启动变慢。截图主要在内存中处理，因此临时缓存可能很少，显示0并不表示功能异常。

继续面向 Android 11+、ARM64。页面和候选面板增加横屏挖孔、刘海、导航栏避让；胶囊落点增加挖孔碰撞处理。大字体下菜单和操作按钮按实际空间换行及测量，底部收起区仍为30dp。权限页面无法直接打开时会尝试标准系统备用入口；不同品牌的后台管理仍由系统决定。上述改动属于兼容增强，不能替代各品牌真机验收。

## 轻毛玻璃与更新记录

「悬浮窗设置」顶部的「使用轻毛玻璃」默认开启，可关闭恢复普通面板。系统原生模糊只覆盖面板背景，文字和按钮保持清晰；模糊半径12dp、最多36物理像素。省电模式、系统关闭模糊或不支持时使用清晰底色。外观不使用持续截图、WebView或背景轮询，面板隐藏后停止效果监听，重复定位复用布局测量。

首页「关于与许可」下方是独立「更新记录」按钮，进入后可查看从0.1.0到V1.3.10的28个开发及测试版本。菜单展开时按全部菜单内容增高面板，关闭后恢复原高度；屏幕或键盘上方空间不足时菜单可滚动，仍保留输入栏和底部收起区。

## 原有入口和读取行为

候选面板底部整条30dp区域可点击收起，小号细线向上箭头在浅色分隔线下方居中，没有文字。右上角菜单第一项是回复风格设置。胶囊默认解锁，解锁时控制显示绿色、锁定时红色；锁定后仍可点击打开面板，不能长按拖动。锁定状态和70%–200%的连续大小调节都会保存，关闭软件和重启手机后保留。滑动实时预览、松手保存；胶囊宽度按Logo和当前状态文字计算，右侧仅少量内边距。放大后状态栏空间不足时放到状态栏下方，可重置位置。

首页的回复风格设置排在功能入口最前面；连接页面不再有“开启聊天悬浮球”按钮。悬浮窗总开关默认开启，仍尊重用户在首页手动关闭的选择。

V1.3.04起按反馈恢复V1.2.13识别流程：能取得原生文字与位置时由代码解析，必要时调用所配置的视觉模型。视觉结果按消息顺序和左右说话方处理，右侧是我、左侧是对方；不会再要求新增OCR、头像或气泡框强校验。视觉提示要求排除背景文字；旧识别协议仍有媒体、引用和语音识别的限制，不能保证所有画面准确。回复、刷新、详情和判断均携带说话方及最后一方信息；最后一句为我时，六条都要求接着我的话继续说。

填入优先自动点击原生输入框，或按已验证的视觉输入位置聚焦；语音模式可使用本次主动读取识别出的左下键盘切换按钮，页面和底部布局改变后不沿用旧位置点击。输入法出现而输入连接尚未就绪时短暂等待。填入失败可自动复制，但明确显示“填入失败…已复制，请手动粘贴”，不冒充写入成功，也不会自动发送；已有草稿仍先确认。

## 配置三个接口

在「模型与连接设置」分别配置判断、回复和视觉接口。

- 判断首选且默认使用 OpenRouter `typesafe/jev-1.13`；此选项的模型固定。也可切换「自定义」，填写兼容 OpenAI 的地址、密钥和判断模型，刷新目录选择模型或直接填写 ID。默认 OpenRouter 密钥与自定义配置分别保留；OpenRouter 密钥留空可复用 OpenRouter 回复／视觉接口的密钥。
- 回复和视觉均可选 OpenRouter、DeepSeek、通义兼容、智谱或自定义地址。输入密钥后刷新模型目录并选择真实模型 ID。OpenRouter 初始回复模型为 `deepseek/deepseek-chat-v3.1`，初始视觉模型为 `qwen/qwen2.5-vl-72b-instruct`；之后保留已保存选择。
- 目录按服务返回展示，图片能力会标注。服务未声明图片能力时，可以在兼容入口填写官方模型 ID，再点「测试图片识别」验证。模型存在不等于支持图片，不能把任意文字模型当视觉模型。
- 点击「测试判断连接」「测试回复连接」「测试图片识别」可分别验证真实调用。测试发送内置示例，会产生少量服务用量。成功后保存。

自定义前缀会保留；根地址的模型目录只有返回 404 才尝试 `/v1/models`。局域网 HTTP 需要明确启用。

## 在微信、QQ与抖音中使用

1. 在「连接聊天应用」允许悬浮窗，启用「对话军师」无障碍服务；悬浮窗总开关默认开启，若此前手动关闭，可在首页重新开启。
2. 进入微信、QQ或抖音的一对一单聊。仅显示悬浮图标，点击图标展开候选窗，再点击右上方「读取信息」。程序读取当前可见对话，自动判断左侧为对方／右侧为我，并生成六条候选，不要求逐条确认。进入聊天、聊天内容变化或仅打开面板均不会采集正文或调用模型。抖音视频流、评论、直播，QQ频道与群聊不生成候选。
3. 微信原生文字或双方位置不可靠时，截取窗口并调用配置的视觉接口；QQ和抖音使用当前应用窗口视觉识别。失败时显示实际状态，点击读取信息重试；不会自动重试或连续截图。
4. 黄色羽扇圆形图标与普通候选窗顶部对齐、边缘相贴。拖动图标或面板标题，两者一起移动。面板按前三条实际文字高度调整，最多474dp并受可用空间限制；六条候选在内部滚动。按钮紧跟正文，正文换行时按钮自然下移。× 收起面板，保留图标；展开时图标也保留。软件图标继续使用用户提供的明黄底木柄版。
5. 离开微信、QQ和抖音，图标和面板隐藏；返回支持的应用仅恢复图标，面板需再次点击展开。窗口检测只读取前台包名、窗口编号和范围，不遍历聊天正文。切换应用后需要重新点击读取信息，旧候选不能填入另一应用。⋯ 设置菜单在面板内部展开。
6. 聊天副驾、狗头军师和恋爱大师知识共同参与分析，不需要切换模式。每批包含恋爱策略；默认显示 Jev 适合度，自定义判断显示「评分」，不表示成功概率。详情解释适用条件、代价及反馈后的下一步。
7. 「刷新换一批」使用已读取的上下文重新生成六条，不重新截图或收集新消息；需要新消息时点「读取信息」。换批和详情均为你主动触发的模型调用。点击复制后面板自动收起，保留图标。填入前做本地窗口与输入框安全检查，不调用模型、不保存新正文，发送由你操作。无法可靠验证时使用复制；关闭面板也取消待完成的填入。
8. 新一轮生成期间保留上一轮候选；切换窗口会使旧回复的填入资格失效。在途读取期间滚动或切换页面会取消此次读取。点击聊天输入框弹出键盘时，面板保持展开，移到输入栏上方；代码为聊天输入栏和间隔预留72dp，空间不足时缩短，候选仍可滚动。填入成功后是否收起由「回复风格设置」里的「填入后面板行为」控制。关闭面板不会自动重新打开。

部分微信版本不暴露原生输入框。本版在 Android 13+ 尝试官方无障碍输入连接；填入前本地检查聊天标题、输入连接及完整草稿，微信已有草稿时询问是否替换。不会自动发送。输入连接不可用时，请先点微信输入框后重试；仍失败时复制回复手动粘贴，面板及「连接诊断 → 最近填入」会说明原因。此前版本的填入与提速已获目标手机用户实测确认。

## 悬浮窗设置

首页和候选面板的 ⋯ 菜单均有「悬浮窗设置」。默认15秒无操作后，收起状态的悬浮球用250毫秒动画滑到最近的左右屏幕边缘，仅露约三分之一；点一下完全露出，再点一下才展开面板。等待时间可填1–3600整数秒，点击保存后保留，下次打开仍使用该时间。

面板展开或正在拖动时暂停计时，关闭面板、复制后收起、拖动结束或唤出完整图标后重新计时。聊天内容变化不会延长悬浮球的倒计时，也不会触发读取或模型请求。切到其他应用或锁屏时移除窗口并取消动画、计时，返回支持的应用再恢复；此前贴边的图标仍保持贴边。启用「减少动效」或系统关闭动画后直接切换位置。键盘或屏幕方向改变时仍为聊天输入栏留出空间。

## 回复风格设置

「全对象回复风格」无需填写联系人名，微信、QQ和抖音都应用。可填写没有标点、简短、详细、浪漫、高情商等要求，保存后下一次读取或刷新使用。优先规则为：有对象专属风格时使用专属风格，没有时使用全对象风格。清空全对象风格不会删除已有专属风格；两者都没有时恢复正常。

首页独立入口「回复风格设置」，不在模型设置中。先选择微信、QQ或抖音，再填写聊天顶部对象备注名及自由格式要求（如没有标点、简短、详细、浪漫、高情商），保存后该对象的六条候选和刷新都应用此风格。同名对象按平台分开，历史聊天也不跨平台匹配。

「已保存对象」列表可查看／编辑各自的完整风格，也可独立删除，删除后恢复正常。旧版只保存了对象名的哈希，已有风格会保留；无法恢复的名称暂显示「旧版对象」。读取到匹配对象后自动补全，或查看后填写对应备注名并保存。原先的全局载入及删除按钮已移除。

首次读取以当前可见消息为上下文，随后仅累积你主动读取到的新消息，不会自动翻阅此前全部历史。每会话本地加密保留最近 50 条，由新消息替换旧消息；每 12 小时清理超额残留，最近 50 条不按时间过期。

## 其他功能与数据

完整咨询支持粘贴对话、目标、背景和草稿；另外提供模拟练习、独立对象资料、记忆和多对象比较。知识页可浏览 45 份来源资料，搜索、新增和编辑个人笔记。对象使用独立身份，不凭同名昵称自动合并。

密钥及本地敏感资料使用 Android Keystore 加密，关闭系统备份。主动读取的聊天文本发送到你配置的回复和判断服务；必要的视觉兜底把本次微信窗口截图发送到你选择的视觉服务。截图在内存处理，不自动写入相册。

「连接诊断」可以显示最近微信窗口尺寸、节点数、窗口类型、读取阶段及视觉模型。导出仅含脱敏状态、耗时和设备信息，不包含聊天正文或密钥。

## 左上角胶囊入口

首页「悬浮窗设置」→「使用左上角胶囊」。默认在时间右侧、摄像头左侧，不在中间摄像头。点击打开现有候选面板；长按后再拖动微调，松手保存位置；短按滑动不会拖动。可在设置页重置位置。开启后隐藏普通球，关闭后恢复；普通球仍保留原拖动及自动贴边方式。

胶囊通过现有无障碍悬浮窗实现，不需要通知权限，不调用原子岛API，不触发模型或收集屏幕。只在微信、QQ、抖音前台、解锁且总开关及服务开启时显示。候选面板仍只有顶部三点可拖动，手动读取、刷新与填入行为保留。

旧版已开启原生岛测试的设置在升级时迁移为胶囊，并关闭旧原生测试；其他用户默认保持普通球。模型密钥、风格、最近记录和自定义秒数保留。屏幕空间不足时入口放到状态栏下方避免挤占时间/摄像头。实际vivo状态栏层级、触摸和各方向仍须手机验收，编译和几何测试不能替代。
