## 实现与边界

- 40个内置应用进入共同的按需读取、视觉确认、会话校验和草稿填入通道；列表外可选择其他已安装应用。通用通道不等于每个最新版本已真机验收。
- 全部48份知识文档入包。固定骨架和最多5份相关资料共同参与；新增温暖/具体欣赏/互惠整合及网络梗/跨语言资料，保留上游原文与许可。真人感优先规则、独立去AI味开关均保留。
- `ReplyPlan.text`仅可发送正文，`translationZh`仅显示。英文短句、日语、韩语及其他文字可进入外语分支；纯中文混入外语正文会拒绝重试。建议提示始终要求中文。离线服务测试验证一次生成加一次排序保留正文/释义配对，没有额外翻译请求。
- 单句粘贴不触发截图或视觉调用、不写入聊天记忆，也不套用上次对象的资料和专属风格。已有单聊身份时填入仍做实时校验；未确认身份或群成员时使用本地草稿会话，只支持复制。
- 粘贴按钮主动请求编辑窗口焦点，再有限等待系统允许访问剪贴板；返回或关闭页面后停止等待。
- 对象页按peerId展示双方原话，群资料汇集当前群，身份分开保存。API33+返回回调与旧版返回均先回记忆总览，保存选中对象并在重新进入时刷新资料。
- 每对象独立加密记录与全局本人资料，原子索引提交；迁移旧单文件，保留撤销、删除墓碑和用户锁定。中断写入保留旧数据，提交后的清理失败记录诊断并下次重试，不造成磁盘/内存真假不一致。
- 旧分类规则通过显式learningPolicy元数据识别，一次性重整现有原文并安排后台补分类；不恢复被删除证据、不覆盖确认资料、不重新截图。真人感关闭或暂停学习时不会自动补分类。
- 片段式中英喜好及一句内多项资料可自动整理；问句/第三人自述不能变成本人喜好。关系观察要求同对象双方依据，保留原话来源；明确关系否定和用户确认优先。没有依据继续保留未知。
- 菜单/主页删改、三处胶囊整数±1%、同行小字说明已修改。填入和截图反馈不再把其他平台统称微信。
