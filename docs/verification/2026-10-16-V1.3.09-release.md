# 对话军师 V1.3.09

本次从已公开的 V1.2.12 更新到 V1.3.09。旧版 Release、标签及下载文件保留。

## 更新内容

- 新增顶部胶囊入口，点击打开面板、长按拖动；支持锁定状态记忆及70%—200%连续大小调节。
- 普通悬浮球闲置15秒后贴边露出约三分之一，可自定义等待时间。
- 候选面板采用可切换的原生轻毛玻璃，模糊半径12dp、上限36像素；隐藏后停止效果监听，拖动复用布局测量。
- 底部加入整条可点击的30dp收起区，小号细线蓝色箭头居中；菜单按内容自适应高度。
- 回复风格设置移到主页顶部，更新记录独立成页面，收录全部27个开发及测试版本。
- 识别已按反馈恢复V1.2.13流程，保留最后一句由我发出时六条候选都以我的身份接着说的规则。
- 改进填入等待和失败提示，保留草稿替换确认与用户自行发送。

## 下载与校验

- `duihua-junshi-V1.3.09.apk`：Android11+、ARM64，可覆盖安装本项目旧版本。
- `duihua-junshi-V1.3.09-source.zip`：本标签对应源码，附源码提交号。
- `SHA256SUMS.txt`：安装包及源码压缩包校验值。

## 验证与限制

255项核心测试、12项设置测试通过；应用与Android测试包编译、Lint、签名、45份知识与许可证、原生库16KB对齐检查通过。真实手机的毛玻璃裁切、输入框焦点、滚动与拖动帧率尚未完成本版设备验收，Android界面测试只是编译通过。识别与模型候选仍须用户核对，不会自动发送消息。
