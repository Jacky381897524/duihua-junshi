# V1.3.11 昵称匹配与面板内风格设置

日期：2026-10-18。版本名 V1.3.11，versionCode 29。此版本为本地测试安装包，尚未上传 GitHub。

## 完成范围

- 按平台和昵称匹配专属风格，专属优先，未匹配时使用全对象风格。不读取头像或账号，不进入联系人资料页。
- 保留昵称原文中的外文、花体、标点、符号、空格、变体选择符、肤色和 ZWJ 组合表情；匹配键使用 NFC 等价编码，不把不同字体、相似字符或不同平台联系人自动合并。
- 标题解析不再因部分标点或较短的 UTF-16 长度限制而丢弃昵称。视觉接口提示要求保留特殊字符；这项提示未进行新的网络模型准确率测试。
- 面板菜单可直接设置专属或全对象风格。支持校正或粘贴昵称、选择已有对象，确认保存后记住识别别名。取消不保存。
- QQ 已知聊天标题节点可用且存在聊天输入区时，优先使用原生完整昵称；其他情况提供可校正的识别结果。
- 打开快捷设置时重新获取当前窗口。已有视觉读取结果只有在新截图标题指纹、窗口、平台、导航代次和当前快照均一致时才复用；否则在本机识别裁切的标题区域。不会发起聊天分析或网络模型调用。
- 风格、昵称和别名仍在应用 filesDir 的加密设置中。清除缓存只处理 cacheDir / externalCacheDirs，不删除这些设置。
- 修复恢复历史会话时丢失 QQ 原生昵称的问题；补充编辑器返回键与系统预测返回回调。

## 实测边界与后续核对

本次最终检查未检测到 USB 设备，因此不声称面板输入、键盘、返回、取消和保存后的真实候选生成已通过真机测试。新增界面测试只完成编译；现有字符单元测试也不代表屏幕 OCR 对所有昵称均正确。

建议安装后在真实单聊打开“面板菜单 → 回复风格设置”，核对昵称，分别保存专属和全对象风格，再读取或刷新候选。昵称识别错字可校正并关联已有对象；截图中的纯表情、复杂字体和截断标题仍可能需要手动粘贴。相同平台完全同名的不同人无法仅靠昵称区分，需使用不同备注。

缓存清理后的风格保留由存储目录隔离、配置往返测试和代码检查支持；重启与覆盖安装后的本机保存效果仍需设备验证。本次没有填入或发送任何聊天消息，没有读取密钥文件，也没有发布新 GitHub Release。
