# V1.4.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付一个修复内嵌设置、展示简短判断、支持逐句分析和三平台群聊的 V1.4.0 本地 APK。

**Architecture:** 沿用 Kotlin 核心模块、Android 原生悬浮窗口、现有视觉/回复/Jev 接口及加密存储。增加同窗口页面栈、带范围的逐句判断、群聊成员与候选目标；使用已有 SessionToken 和取消机制拒绝过期结果。先建立会话数据约定，再按依赖顺序接入 UI，不整体重写捕获与填入流程。

**Tech Stack:** Kotlin/JVM 17、Android View、Gson、ML Kit、现有 HttpTransport、JUnit、Android instrumentation。

**执行结果（2026-10-19）：** 任务1–12的代码、回归与本地打包已实施；最终证据见 `docs/verification/2026-10-19-v1.4.0.md`。设备断连，新增Android设备用例仅编译，真实UI/群聊及联网模型验收待用户安装测试。下方设备条目保留为待验收，未把编译写成真机通过。

**Spec:** `docs/superpowers/specs/2026-10-19-v1.4.0-panel-group-analysis-design.md`（已获用户确认）。

路径约定：下文 `core/` 指 `android/core/src/main/kotlin/com/loveadvisor/core/`，`app/` 指 `android/app/src/main/java/com/loveadvisor/android/`。所有以 Test.kt 结尾的路径解析为测试源集：core 测试位于同包的 `android/core/src/test/kotlin/com/loveadvisor/core/`，app 设备测试位于同包的 `android/app/src/androidTest/java/com/loveadvisor/android/`。只写测试类名时，其包与本任务被测组件一致。

## Global Constraints

- 版本 V1.4.0，versionCode 30；Android 11+、ARM64、既有签名。
- 面板设置不启动 Activity、不创建系统 Spinner/AlertDialog 选择窗口；主页设置入口保留。
- 保存最小高度 48dp，返回最小高度 44dp，大字体允许增高；宽薄收起区保留。
- 专属昵称、别名和风格保存在持久加密设置；清除缓存不删除。
- 面板意图和建议分别最多两行；等级 1–3 绿色安全、4–6 橙色一般、7–9 红色危险，未知为待判断。
- 逐句判断按目标消息及其之前已读取上下文，按点击请求；无有效读取只提示，不请求。
- 群聊支持微信/QQ/抖音原生群会话；默认 100 条已读上下文，允许 50/100/200；单聊保持 50 条。
- 群聊六条可分配不同话题；指定消息时六条都回应该消息。无自动 @、原生引用或发送。
- 私聊与群聊风格隔离；群专属 → 全群风格 → 自然表达，不强制恋爱策略。
- 不推断账号或保存头像；不自动翻历史，不持续截图，不启用实时好感度或自动长期记忆写入。
- 不读取或输出密钥作日志；网络连接测试仅在用户点击时进行。
- 不覆盖既有 APK，不发布 GitHub；源码与本地安装包为本次交付。

## Review Focus

1. 编辑面板时微信已有草稿/正在输入：设置键盘必须与聊天输入区隔离，填入不能写到设置框。由任务3、11验证。
2. 同名群、成员计数变化、未识别成员：不能串历史、误用风格或把所有左侧视为同一个人。由任务1、2、7验证。
3. 切消息、对象、模型后旧网络返回：不能覆盖当前判断或候选。由任务8、10验证。
4. Jev 缺概率、NaN、百分比分布不完整：不补造百分比，不把适合度当意图概率。由任务9验证。
5. 暗色、大字体、横屏及软键盘：按钮可读可触，保存/返回可滚动到达，空白处不漏点击到底层候选。由任务3、4、5验证。
