# 对话军师 V1.7.13 修复保护版

Android 聊天助手：读取当前聊天后生成六条不同思路的候选回复，支持选句回复、中文建议、默认／袪味／真实三种表达模式、人物记忆与口吻学习、单句粘贴分析，以及外语候选与中文释义。外语候选填入时仅填入外语正文。

本次包含截至 V1.7.13 的功能与修复，重点改进已读对象候选恢复、长备注核对，以及有聊天依据的重复缓存整理。每个对象保留最近成功的一批，默认缓存约 10 个对象，可在设置中调整至最多 20 个，单聊和群聊共用容量。标题核对及恢复在本地进行，不增加模型请求；生成回复仍依赖用户配置的模型服务。

## 安装与校验

从 [V1.7.13 Releases](https://github.com/Jacky381897524/duihua-junshi/releases/tag/v1.7.13) 下载 `duihua-junshi-V1.7.13.apk`，覆盖安装已有版本。安装包沿用原签名证书，校验值见 `SHA256SUMS.txt`。保留原有设置、人物记忆与候选缓存。
